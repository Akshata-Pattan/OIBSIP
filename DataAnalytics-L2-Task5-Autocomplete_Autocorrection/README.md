# ✨ NLP Autocomplete & Autocorrect System

An NLP-based **Autocomplete and Autocorrect System** developed using Python and traditional Natural Language Processing techniques.

The project combines **Gutenberg, Brown, and WikiText-2 corpora** with a general English vocabulary to build a broad language resource. The autocomplete module uses **Bigram and Trigram language models** to predict likely next words, while the autocorrect module uses **Levenshtein Edit Distance** and word-frequency ranking to suggest spelling corrections.

## 🚀 Key Features

- 🔤 Bigram and Trigram-based autocomplete
- ✏️ Spelling correction using Levenshtein Edit Distance
- 📊 Frequency-based candidate ranking
- 📚 Multi-corpus training
- 🌐 Interactive Streamlit web application
- 📈 Accuracy, Precision, and Recall evaluation

## 🧠 Technologies Used

**Python • NLTK • Pandas • Matplotlib • WordFreq • Streamlit • Pickle**

## 📊 Results

The autocorrect system was evaluated on **20 misspelled words** and achieved:

- **Accuracy: 80%**
- **Precision: 80%**
- **Recall: 80%**

The system correctly predicted **16 out of 20** expected corrections.

## 🌐 Application

The Streamlit application allows users to enter words or phrases and receive autocomplete predictions and autocorrect suggestions through an interactive interface.
