# ✨ NLP Autocomplete & Autocorrect System

## 🎓 Internship Task

**Oasis Infobyte Internship – Task 5**  

An NLP-based **Autocomplete and Autocorrect System** developed using Python and traditional NLP techniques.

The project combines **Gutenberg, Brown, and WikiText-2 corpora** with general English vocabulary. It uses **Bigram and Trigram language models** for autocomplete and **Levenshtein Edit Distance** with word-frequency ranking for autocorrect.

## 🚀 Key Features

- 🔤 Bigram & Trigram autocomplete
- ✏️ Spelling correction
- 📊 Frequency-based ranking
- 📚 Multi-corpus training
- 📈 Model evaluation

## 🧠 Technologies Used

**Python • NLTK • Pandas • Matplotlib • WordFreq • Pickle • Google Colab**

## 📊 Results

Evaluated on **20 misspelled words**:

- **Accuracy:** 80%
- **Precision:** 80%
- **Recall:** 80%
- **Correct Predictions:** 16/20

## 📓 Project Notebook

The notebook contains the complete implementation, including data preprocessing, language model development, autocomplete, autocorrect, testing, and evaluation.
