# Wine Quality Prediction using Machine Learning

## 📌 Project Overview

This project was completed as part of the **Oasis Infobyte Data Analytics Internship (Level 2 - Task 2)**.

The objective of this project is to build a **Machine Learning model** that predicts the quality of wine based on its physicochemical properties such as acidity, alcohol content, pH, sulphates, density, and other chemical characteristics.

---

## 🎯 Objective

- Analyze the wine quality dataset using Exploratory Data Analysis (EDA).
- Perform data preprocessing.
- Train a Random Forest Classifier.
- Predict wine quality for unseen samples.
- Evaluate the model using classification metrics.

---

## 📂 Dataset

- Dataset: **WineQT Dataset**
- Format: CSV
- Total Records: **1,143**
- Total Features: **13**

## 🤖 Machine Learning

**Algorithm Used:**

- Model Evaluation

## 📈 Model Performance

- **Accuracy Score:** **70.31%**

### Evaluation Metrics

- Accuracy Score

The Random Forest Classifier achieved an **Accuracy Score of approximately 70.31%**, demonstrating good predictive performance on the given dataset.
