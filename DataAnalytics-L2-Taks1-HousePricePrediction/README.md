# House Price Prediction using Machine Learning

## 📌 Project Overview
This project was completed as part of the **Oasis Infobyte Data Analytics Internship (Level 2 - Task 1)**.

The objective of this project is to build a **Machine Learning model** that predicts house prices based on various property features such as bedrooms, bathrooms, living area, floors, grade, location, and other house characteristics.

---

## 🎯 Objective
- Analyze the housing dataset using Exploratory Data Analysis (EDA).
- Preprocess the dataset.
- Train a Linear Regression model.
- Predict house prices for unseen data.
- Evaluate the model using regression metrics.

---

## 📂 Dataset
- Dataset: Housing Price Dataset
- Format: CSV
- Total Records: **21,613**
- Total Features: **21**

---

## 🤖 Machine Learning
**Algorithm Used:**
- Linear Regression

### Workflow
- Feature Selection
- Train-Test Split (80:20)
- Model Training
- House Price Prediction
- Model Evaluation
- Prediction for a New House

---

## 📈 Model Performance

- **Mean Squared Error (MSE):** 45,173,027,114.56
- **R² Score:** **0.7012**

The model explains approximately **70% of the variation** in house prices, indicating good predictive performance.
